# Northstar 0.3.29

## New

- **Northstar branding.** The desktop app ships as **Northstar.app** with the Northstar name in the menu bar and sidebar. Download installers use **Northstar-** file names on [app.bada.com.ng/download](https://app.bada.com.ng/download).
- **Account service.** Sign in under Settings → Account & billing links this computer to your app.bada.com.ng account (device limits apply).

## Notes

- macOS builds are ad-hoc signed until Apple Developer ID notarization is configured in CI. Use **Control-click → Open** the first time if Gatekeeper blocks launch.
- This release is the Northstar commercial fork; installed coding CLIs still authenticate with their own providers.
